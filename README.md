# Earlier portfolio website

An earlier Next.js portfolio implementation retained as part of the H&H project history.

The current portfolio is available at [thehnh.tech](https://www.thehnh.tech/), with its source in [GameNotCreator/me](https://github.com/GameNotCreator/me).

## Development

```sh
npm install
npm run dev
```

Open the local address printed by Next.js. The manifest also defines `npm run build`, `npm start` and `npm run lint`. Historical dependencies and external links should be reviewed before deploying this version again.

## Framework origin

This project was bootstrapped with [create-next-app](https://github.com/vercel/next.js/tree/canary/packages/create-next-app). See the [Next.js documentation](https://nextjs.org/docs) for framework concepts and the version-specific deployment guidance.
